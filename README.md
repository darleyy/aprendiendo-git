# aprendiendo-git

Proyecto de práctica para repasar **Git**, **GitHub** y **desarrollo web** desde cero.

## Sobre este proyecto
Página web de presentación personal construida con HTML y CSS, usando control de versiones con Git y GitHub como parte del flujo de trabajo (branches, commits, Pull Requests y merges).

## Tecnologías
- HTML
- CSS
- Git / GitHub

## Flujo de trabajo practicado
Cada funcionalidad se desarrolló en una branch separada, siguiendo el flujo:
`branch → cambios → commit → push → Pull Request → revisión → merge`

- Pull Requests
- Merge de cambios (sin conflictos)
